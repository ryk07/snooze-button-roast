One original line roasting an alarm clock that rings at 6 AM on a Saturday, for the [Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6) bounty on make.fun.

## Entry

`main.py` (Python 3, standard library only) writes a single line to `/output/entry.txt`:

> My alarm clock rang at 6 AM on a Saturday like a snitch who couldn't wait to tell Monday I'd been sleeping in.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is one line, 110 characters — inside the 1–200 character gate.
